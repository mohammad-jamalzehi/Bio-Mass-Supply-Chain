# Biomass research website

**Authors:** Mohamad Jamalzehi and Kosar Ghazali.

Run from the repository root to validate and regenerate the snapshot:

    python -B -m unittest discover -s tests -v
    python -B web/scripts/export.py

Use the repository's pinned Python dependencies and Node.js 22.12 or newer.
From web:

    npm ci
    npm test
    npm run dev
    npm run build
    npm run preview

In PowerShell use npm.cmd if npm is blocked by execution policy. Open
the URL Vite prints at the /Bio-Mass-Supply-Chain/ base path. Build output
is in web/dist and can be used as a GitHub Pages artifact after publication
is approved. Set Pages to GitHub Actions and manually start the workflow
when approval has been granted. The site bundles cited source snapshots; regenerate them with
`python -B web/scripts/sources.py` from the repository root.

The Markdown files in src/content contain the academic sections.
equations.json maps the corrected equations to implementation lines.
results.json is generated by running the Phase 2 and Phase 3 solvers and
reading the existing Phase 4 run metadata. Annual diagnostics are displayed
as time-limited and provisional. The interactive network uses only the
synthetic Phase 3 dispatch data. No network requests to a solver are needed.
